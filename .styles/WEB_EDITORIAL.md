# WEB_EDITORIAL.md

## Intent

Create expressive, story-led web pages with strong typography, deliberate pacing, and adaptable media composition.

## Production Rules

- Establish a type hierarchy for display, heading, deck, body, caption, metadata, and navigation roles.
- Compose around narrative sequence and reading rhythm rather than repeating identical card grids.
- Use asymmetry only when document order, focus order, and responsive reflow remain clear.
- Give media captions, credits, alternative text, aspect behavior, and loading treatment explicit rules.
- Keep promotional calls to action honest, limited, and visually distinct from editorial content.

## Acceptance Checks

- Heading order and reading order remain logical without visual styling.
- Typography tolerates long titles, localization, zoom, and small screens.
- Media does not cause unexpected layout movement or obscure essential copy.
- Primary actions remain clear without interrupting the reading flow coercively.

## Role Fit

Use with `web-experience-designer`, `technical-writer`, `art-director`, and `frontend-developer`.

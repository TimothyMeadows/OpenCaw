# WEB_TECHNICAL_GRID.md

## Intent

Create precise, information-dense web experiences shaped by measurement, modular grids, and visible system structure.

## Production Rules

- Define a responsive column, spacing, baseline, and alignment system before composing pages.
- Use compact labels, tabular numerals, diagrams, and monospaced accents only where they improve comprehension.
- Keep grid lines subordinate to content and remove decorative lines that imply false relationships.
- Use restrained color with explicit semantic status tokens and redundant non-color indicators.
- Make dense tables and panels reflow, scroll, or summarize without shrinking beyond usable sizes.

## Acceptance Checks

- Alignment remains consistent across breakpoints and variable content lengths.
- Data groupings are understandable without decorative grid lines.
- Keyboard focus, selection, status, and error states remain visually distinct.
- Dense views support zoom, narrow screens, and assistive-technology reading order.

## Role Fit

Use with `web-experience-designer`, `frontend-developer`, `technical-writer`, and data-focused roles.

# Develop Original Brand Directions

## When to use

- Creating several visual directions for one product or campaign.
- Using references for visual grammar without copying identity.
- Revising a concept that feels generic or too close to another work.

## Workflow

1. Define audience, promise, personality, channels, production constraints, and required wordmarks.
2. Separate transferable grammar from names, marks, characters, compositions, palettes, and other signature elements.
3. Set a similarity limit and create a differentiation matrix across shape, type, palette, material, imagery, composition, and motion.
4. Develop at least three directions with distinct governing ideas and rejection criteria.
5. Write production briefs or generation prompts using the active style contract.
6. Review outputs for identity clarity, accessibility, text accuracy, and reference distance.

## Output

- A comparison matrix of original directions.
- A concise brief for each direction with visual rules and exclusions.
- Acceptance criteria and a recommended direction with tradeoffs.

## Guardrails

- Do not imitate a living artist, protected character, logo, or signature layout.
- Do not use a name change as the only differentiation.
- Do not describe generated concepts as production-ready assets without handoff validation.

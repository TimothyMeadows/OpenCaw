# Non-authorizing VOICE templates

These files grant no recording access, setup, license acceptance, synthesis, human acceptance, distribution, cloned-output disclosure or promotion. Zero hashes intentionally identify no real evidence. References do not contain recordings or transcripts. Copy the selected template into an owned active-task input area and supply current scoped evidence before `voice-pipeline.sh brief --root ROOT --brief FILE`. Used immutable briefs are revised with ancestry, never edited in place.

`brief.local.json` requests preset speech with all native sampling controls explicit. `brief.cloning.local.json` selects Base cloning with preset:null/expression:'' and references four separate canonical local files. `brief.cloud.json` plans only preset-speech provenance import; its language/preset/expression are explicitly provider-declared values, not native catalogue claims. CLOUD cloning is unavailable under local-only consent. No command uploads references, transcribes audio or selects a fallback provider.

LOCAL supports the native languages/presets and autoregressive sampling bounds in the brief schema: maximumNewTokens 3..2048, both sampling flags true, temperatures (0,2], topK 1..200, topP (0,1] and repetitionPenalty 1..2. A batch has 1..4 exact spoken-text items within 4096 characters AND UTF-8 bytes each. Negative prompt is empty; loops/fixed seconds/diffusion controls are unsupported. Actual output duration is bounded by maximumAudioSeconds (at most120), not synthesized to a requested number of seconds. Backend and version/output IDs belong to the coordinator. Each LOCAL preset/cloning installation must match its own actual native backend and license evidence.

Cloning requires actual audio (1 byte..20 MiB M4A/WAV), exact strict UTF-8 transcript (1 byte..16 KiB, nonempty, at most4096 characters/no NUL), `recording-rights.json` and `consent.json`. These four paths must differ ignoring case. Native consent sourceEvidence is a fifth distinct canonical local file that records actual human authority; it cannot be the recording or consent itself. All evidence remains local and is rehashed. Templates do not establish a speaker's identity or permission.

`local-use.json` supplies the host-purpose binding without changing native schemas: exact task/purpose/native scope, complete ordered item/reference set, generationAllowed and a real scoped source. False generationAllowed can support original-task planning/import; fresh dispatch requires true/current task plus actual native consent and prompt rights. QA-only local-voice-cloning-qa additionally requires the existing native consented-cloning acceptance case, candidate/revision and approval allowance. New task/domain/workspace registration does not replenish one-candidate-plus-one-revision history.

Optional historicalRoot is LOCAL import-only and must identify an existing original root strictly beneath the current project, matching the untouched original context.projectRoot and neutral wrapper. Preserve original native JSON/tasks/consent/source identities. Native item/reference/consent fields stay original-root-relative and are remapped only for reading; new localUse/disclosure/source/output identities are current-root-relative. Do not retarget old private paths, fabricate ancestry or use historicalRoot for new generation.

Content/runtime examples deliberately say rejected and omit output identities. Complete them only with current assetSha256, exact complete ordered outputs, actual human source, reviewer/reason and truthful verdict. Acceptance needs complete listening, spokenTextReviewed, pronunciationReviewed, artifactsAcceptable and presetOrReferenceMatchReviewed. Metadata and synthetic waveforms cannot establish these facts.

`distribution.json` separately binds current task/purpose to runtime rights and publicDisclosureConfirmed. `runtime-evidence.json` records actual selected-engine identity, exact outputs, spatialization, loopIntent:false and playback/load/disposal review. Use the resolver's current engine identity, not the placeholder. `runtime-review.json` references these records; remove disclosureEvidence for preset speech. Cloning additionally needs `disclosure.json` with exact current outputs AND complete ordered item/reference set, task/purpose, disclosureAllowed and an actual separate disclosure grant. Local/QA consent is insufficient; a later grant may cover existing outputs without rewriting native consent. Reusing a source is allowed only if its actual scope supports all assertions.

Rehash every nested consent/local-use/disclosure/distribution/human/target source at handoff and promotion. Handoff copies nothing. Promotion/recovery is separate exact-output/target authorization with no overwrite and retained failures. Keep private recordings, transcripts, conditioning, generated speech and their identifying hashes in local task state; public reports contain nonidentifying summaries only. No template or source merge constitutes real human review or promotion permission.

# MUSIC production pipeline

## Scope

MUSIC owns instrumental and supplied-lyric tracks. AUDIO owns SFX/ambience; VOICE owns spoken speech/cloning. These domains can load together with any visual pipeline without changing STYLE.md or each other's selection/state.

## Foundation readiness

This declaration and its optional MUSIC.md contract are available. The complete domain production command is not implemented in this foundation revision; the dedicated music task extends this declaration and registers its entry point. Resolving or validating this contract does not execute generation or imply model installation/readiness.

## Production requirements

- Distinguish instrumental from supplied-lyric songs. Bind duration, structure, mood/instrumentation, gameplay purpose, loop intent, finite budgets, exact supplied lyrics and their rights.
- MEDIA.md owns explicit CLOUD/LOCAL selection, rights, setup, budgets and staging. LOCAL uses the verified Bubo music API; ACE-Step's optional planning LM remains disabled. Unsupported controls fail explicitly.
- Preserve immutable versions, failed attempts, original amplitudes, exact native settings/outputs and one physically shared native approval/attempt ledger.
- Review the complete track for intended instrumental/vocal content, every supplied line when applicable, artifacts and usable sound. Instrumental output cannot satisfy a supplied-lyric song. A loop flag does not establish a reviewed seamless boundary.
- Keep target/runtime acceptance and explicit promotion separate. No unimplemented stem generation, editing, mastering, automatic lyric provider or implicit normalization/promotion is promised.

Follow the shared lifecycle and bounded native GPU/process ownership. MUSIC has no runtime dependency on AUDIO or VOICE; no provider fallback is automatic.

# Non-authorizing MUSIC templates

These examples grant no setup, generation, listening acceptance, distribution or promotion. Zero hashes intentionally cannot identify real evidence. Copy a template into the active task's owned input area, replace paths/hashes with current applicable evidence and run `music-pipeline.sh brief --root ROOT --brief FILE` before initialization. Obtain missing permissions separately. Never edit a used immutable brief or accepted original; revise with ancestry.

`brief.local.json` is instrumental; `brief.song.local.json` preserves an original two-line supplied text. Both use actual Bubo settings, native maximum* budgets and item seconds. Mood/instrumentation/structure belong in the caption, not unsupported request fields. LOCAL supports whole 10..600 seconds, 1..8 steps, guidance 1, empty negative prompt and nonnegative int32 seeds. All seven music options are explicit. Instrumental text is empty/language unknown; songs require actual text and a supported explicit language. Planning LM/automatic lyrics, reference audio, normalization, mastering/editing and stems are unavailable. The pipeline owns backend and version-specific request/output IDs.

`lyrics-rights.json` is a record referenced by the song brief's typed `lyricsRights`. Hash the exact UTF-8 `music.lyrics` string, preserving every line ending and whitespace; cover all items in their original order. Set purpose exactly equal to the brief. Replace the source with actual lyric permission evidence. `generationAllowed:false` allows scoped planning/import without new generation. Actual dispatch additionally needs current-task lyric and native prompt generation permission, native installation/license admission and any existing approval identity. Historical permission does not authorize new generation or distribution.

`brief.cloud.json` preserves song mode/text/rights while omitting native installation/settings and diffusion controls. Import separately authorized session provenance. No unattended CLOUD adapter is invented, and missing authoritative analysis remains technically ineligible. LOCAL is never an automatic fallback.

Optional LOCAL `historicalRoot` supports import from an existing original root strictly below the current project. Preserve the original JSON and same neutral-wrapper value; new references use canonical current-project-relative paths. Bind original request/context/result/manifest, actual revision/build/catalogue and worker metadata. The original context.projectRoot must still resolve to that declared directory. Do not guess a runtime/model pin, retarget cross-machine paths or use historical-root briefs for generation.

Review examples deliberately say rejected and contain no output identities. Actual acceptance binds the current assetSha256, complete ordered outputs, human source, reviewer and reason. Content criteria require complete-track listening, brief/vocal intent, artifacts and head/tail; songs also require everySuppliedLineReviewed. Review supplied section markers as structure directions, preserving their text without requiring the marker names to be sung. For an instrumental remove the song-only criterion. Remove loopSeamReviewed if no loop is claimed, or record an actual true seam verdict. A metadata lyric match cannot establish audible singing or line fidelity.

Actual runtime review additionally references an `hephaera-music-distribution/v1` record (`task`, exact `purpose`, `rightsConfirmed:true`, typed `sourceEvidence`) and `hephaera-music-runtime-evidence/v1` (`task`, current `engine`, exact `outputs`, matching `spatialization`/`loopIntent`, actual `playbackReviewed`, `loadDisposeReviewed`, applicable `loopSeamReviewed`, typed `sourceEvidence`). Rehash lyric and distribution sources at handoff/promotion. Generation permission and accepted license metadata do not confer distribution permission.

Use shared handoff/promotion authorization formats only after actual current reviews. Handoff copies nothing. Promotion is separate, exact-output, no-overwrite and explicitly authorized; examples, native QA and source merges grant no runtime promotion.
